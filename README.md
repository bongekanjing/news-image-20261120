# news-image-20261120

A newspaper front page summing up the world news of Friday 20 November 2026 in one image.

## The day, in one picture

- **World Court rules Myanmar committed genocide** — the International Court of Justice rules 9–6 that Myanmar committed genocide against the Rohingya, the first time the court has held a state responsible for genocide.
- **Trump, Xi and Putin meet in Shenzhen** — the first three-way summit ends in a joint peace declaration, with no mention of Ukraine or Iran.
- **Kyiv bridges hit in night raid** — Russian missiles strike three bridges; 8 killed and 28 hurt across nine regions.
- **Missile hits Riyadh tower** — a Houthi strike damages the Saudi sovereign wealth fund tower in the capital's financial district.
- **Stocks slide for a fifth day** — the Nikkei falls 4.8% and the S&P 500 drops 2% after Anthropic's Nasdaq debut.
- **Also today** — Cyclone Akvan makes landfall in Odisha; Israeli troops cross Gaza's Yellow Line; the COP31 draft drops the fossil-fuel phase-out; Kenya's last Ebola patient is discharged.

The image is an original illustration drawn for this entry with a Python script (Pillow, build-time only). `main.py` (Python 3.13, standard library only) copies it to the output directory, so both grader runs write the same bytes.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
